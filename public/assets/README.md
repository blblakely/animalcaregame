# Original pixel-art assets

All artwork in this directory was generated specifically for Paw Haven and is loaded as PNG textures by Phaser.

- `environment/shelter-interior.png` — complete top-down shelter interior with kennels, reception, computer, pantry, wash station, lounge, entrance, flooring, walls, windows and decorations.
- `sprites/animals-atlas.png` — 4×3 atlas containing four dogs, four cats and four rabbits with distinct coats and markings.
- `sprites/player.png` — transparent shelter-worker sprite.
- `sprites/people-atlas-source.png` — 4×2 visitor atlas with varied people and clothing.
- `items/enrichment-atlas.png` — 4×3 prop atlas containing eight enrichment items, bowls, a plant and food bags.

The visual brief requested original cozy 16-bit pixel art, a warm honey/sage/coral palette, readable top-down silhouettes, deliberate square pixels, and no copied game assets, names, logos or characters.
